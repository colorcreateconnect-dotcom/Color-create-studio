# Yanna Mini Popup Pack 🎬

A reusable animation asset system for the **Yanna** TikTok series — a stylized 3D
chibi "inner voice" pop-up character (Lizzie McGuire style). Drop your stickers
in, run one command, and get CapCut-ready animated overlays (transparent WebM +
GIF + PNG sequence) plus a full manifest of when and how to use each reaction.

---

## 🚀 Quick start (3 steps)

```bash
# 0. one-time setup
pip install -r scripts/requirements.txt

# 1. drop your transparent PNG stickers into source/reactions/
#    named:  yanna_reaction_<name>.png   (e.g. yanna_reaction_side_eye.png)

# 2. check they're clean transparent cut-outs
python3 scripts/check_transparency.py

# 3. animate everything (each sticker gets its recommended preset from the manifest)
python3 scripts/animate.py
```

Outputs appear in `exports/gif`, `exports/webm`, and `exports/png-sequence`.
Want to test the engine before you have files? `python3 scripts/animate.py --self-test`.

## 🎞️ The 7 animation presets

| Preset | Motion | Feels like |
|---|---|---|
| `pop_in` | pop-in bounce with overshoot + settle | entrance / punchline reveal |
| `wiggle` | side-to-side sway + tilt | playful, sassy, waving |
| `clap_shake` | fast tiny horizontal shake | claps, alerts, reminders |
| `slide_in` | dramatic slide-in from the edge | making an entrance |
| `exit_slide` | anticipation dip then slide + fade out | outro / leaving the scene |
| `float` | gentle up-down hover + micro-tilt | chill, soft-life, calm |
| `pulse` | scale heartbeat | attention grab, "look here" |

Run one preset across all stickers: `python3 scripts/animate.py --preset float`
Render just a few: `python3 scripts/animate.py --only side_eye exit_slide`
Pick formats: `python3 scripts/animate.py --formats gif webm`

## 🔒 Character lock (do not change)

Every sticker must stay the **same Yanna**. If you ever regenerate art, match:

- Brown zip-front top
- Pink leopard wrap skirt
- Long braids
- Sunglasses
- Gold jewelry (hoop earrings, layered necklaces, ankle bracelet)
- Smartwatch
- Sandals
- Cheek dimples (visible when smiling)
- Thigh tattoo (Mongolian flowers + bow ribbon + *"Never regret anything that once made you smile"*)

**Palette:** `#7B4B2E` `#A56A43` `#D7A27C` `#2F1F16` `#8E6B95` `#E7C079` `#F2E5D0`

Rules: **do not alter the character design, do not create a new character.** These
are stored in `manifest/yanna_manifest.json → character_lock` for reference.
