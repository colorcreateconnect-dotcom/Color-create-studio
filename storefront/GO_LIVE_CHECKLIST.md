# Pre-Launch & Go-Live Checklist — Color Create Studio

Work top to bottom. The **gate** is images + publishing — almost nothing looks right until
products have photos and are set to Active.

---

## Phase 1 — Catalog finish (the gate) 🚪
- [ ] **Add product images** to each product (photos or mockups). Paste alt text from
      `shopify/seo_reference.csv` as you upload.
- [ ] **Spot-check pricing** across tiers (a few per collection) — confirm the ladder reads
      right in context (see `shopify/PRICING_GUIDE.md`).
- [ ] **Fix the legacy "$25 Custom Family Group Shirts" product** — either update it to match
      the new $35 ladder or unpublish it, so it doesn't anchor customers low.
- [ ] **Publish products:** Products → select all → **Actions → Set as Active**. (They imported
      as Draft on purpose.) Do this in batches as images get added if you prefer.

## Phase 2 — Collections 🗂️
- [ ] Confirm all **16 collections** show product counts now that products are Active.
- [ ] **Add a collection image** to each (Collections → click one → add image).
- [ ] **Publish each collection** (set its sales-channel visibility to Online Store).
- [ ] Verify SEO title/description are filled (from `shopify/COLLECTIONS_SETUP.md`).

## Phase 3 — Homepage & pages 🏠
- [ ] **Wire collections into the homepage** sections (Theme editor) — follow
      `HOMEPAGE_WIRING_GUIDE.md`. Confirm "$0 / connect a collection" placeholders are gone.
- [ ] Publish the **Our Story** page (`ABOUT_ORIGIN_STORY.md`) + add your photo; link it from
      the hero CTA and footer.
- [ ] **Connect your existing FAQ** page to the nav + footer (you already have the content).
- [ ] Confirm **Contact** page works (test the form sends to your Gmail).
- [ ] Check **nav links** (Shop, Templates, Portfolio, FAQ) all resolve — no empty pages.
- [ ] **Hide the empty social-feed section** (or connect an IG feed app) so nothing looks unfinished.

## Phase 4 — Store settings (must-haves before selling) ⚙️
- [ ] **Payments** — activate Shopify Payments / PayPal; run a real test order.
- [ ] **Shipping** — set rates/profiles for physical (Print + Ship) items; mark digital/service
      items as **no shipping required** (already flagged in the CSV).
- [ ] **Digital delivery** — choose how download/Canva-link products are delivered
      (a digital-downloads app, or manual email for now → PRISM can automate later).
- [ ] **Taxes** — configure tax regions.
- [ ] **Policies** — add Refund, Privacy, Terms, Shipping (Settings → Policies; Shopify can
      generate starter templates — edit for custom/digital "no refund on personalized" terms).
- [ ] **Notifications** — confirm order/confirmation emails are branded.
- [ ] **Domain** — `colorcreatestudio.com` is connected and SSL active.

## Phase 5 — Pre-launch QA 🔍
- [ ] Place a **test order** (set a 100%-off code or use Bogus Gateway) for: a physical item,
      a digital item, and a custom-service item — confirm each checks out correctly.
- [ ] View the store on **mobile** — most traffic will be phone; check hero, collections, PDP.
- [ ] Click into **3–4 products per tier** — titles, prices, variants, descriptions, images all correct.
- [ ] Confirm **variant labels** read clearly (Format / Edition / Service Level / Delivery).
- [ ] Search a product in the store search bar — confirm it returns.

## Phase 6 — Launch 🚀
- [ ] **Remove storefront password** (Online Store → Preferences) to go public.
- [ ] Submit sitemap / confirm SEO preferences (Online Store → Preferences → Google etc.).
- [ ] Kick off **Day 8 "We're OPEN"** posts from `marketing/LAUNCH_CONTENT_CALENDAR.md`.
- [ ] Pin launch post + update IG/TikTok/FB bios with the store link.
- [ ] Watch first orders; reply to every comment/DM fast (warm launch = best reach window).

## Phase 7 — Post-launch (week 1) 📈
- [ ] Turn on an **abandoned-cart email**.
- [ ] Add a **bestsellers** automated collection once sales data exists; feature it on the homepage.
- [ ] Collect first **reviews/UGC** → reshare (Day 13 content slot).
- [ ] Note any pricing that's too low/high after real buyer reactions and adjust in the generator.

---

### Fastest path if you're short on time
**Images → publish products → collection images → wire homepage → fix the $25 product →
payments + shipping + policies → test order → remove password → launch posts.**
