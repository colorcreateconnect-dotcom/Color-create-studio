# Yanna Mini Prompt Bank

The locked character DNA plus reusable prompt formulas so every new
generation stays on-model. Paste the Character Lock block into every
prompt, then swap the scenario block.


## Formula 1: New 5x5 Pose Grid

```
[CHARACTER LOCK]
Create a 5x5 grid of 25 full-body poses of this exact same character.
Each cell numbered 1-25 in the top left corner. Poses: [list your 25].
Identical character model, outfit, and proportions in every cell.
Even spacing, same camera distance, full body visible in each cell,
flat cream background, no cropping of limbs.
```

## Consistency Rules (non-negotiable)

1. Never describe the character from scratch. Always paste the lock.
2. Generate grids on the FLAT CREAM background only. Gradients and
   vignettes fight the background remover.
3. Ask for even grid spacing and full bodies with no limb cropping.
4. If a generation drifts (wrong skirt, missing dimples, changed
   braid length), regenerate. Do not keep off-model cells; they
   break the illusion that this is one consistent character.
5. Reference upload beats text: when the tool supports image
   reference, attach 01_Master_Character/yanna_master_reference_sheet.png
   alongside the prompt.
